An AI-powered skincare & beauty intelligence platform designed to help users make informed decisions beyond hype.

**What I built/worked on:**

- 🤖 **Blossom** — personalized agentic chatbot using **LangChain + LangGraph + Groq + Tavily**
- 🔎 **RAG pipeline** that researches dermatologist-approved websites and research papers
- 👤 Personalized responses based on **skin type, concerns & budget**
- 🧴 **Product Intelligence Engine** with ingredient analysis
- 💬 Reddit review collection + **NLP sentiment analysis**
- 📰 **Autonomous Weekly Bulletin Agent** that researches trending products every week
- ⏰ Automated workflows using **APScheduler**
