## 🧠 Featured Project

### 🌸 DeInfluencer AI
AI based skincare intelligence platform — personalized product recommendations backed by dermatology research instead of hype.

**Architecture**
* Blossom RAG agent → LangChain + LangGraph + Groq + Tavily
* RAG pipeline → dermatologist-approved sources & research papers
* Product Intelligence Engine → product details web scraped + Reddit posts sentiment analysis (NLP)
* Autonomous Weekly Bulletin Agent → (displays trending products and their details)
* Backend: FastAPI + Supabase → deployed on Render & Vercel

> **Don't buy what's viral. Buy what's best for you.**

### 🗝️ 3D DSA Escape Rooms
Browser-based 3D escape rooms that teach data structures through interactive puzzles — built with A-Frame (WebXR) and GLTF environments.

**Architecture**
* 3D dungeon exploration → A-Frame + Three.js, WASD/look-controls navigation
* Proximity-triggered puzzles → real-time hit-detection loop
* Puzzle engine → dynamically rendered questions, hints, scoring, timer

**Stack:** A-Frame · Three.js · JavaScript (vanilla) · HTML5/CSS3 · GLTF/GLB 3D models

### ✍️ AI Technical Blog Writer
* Multi-agent blog generator using LangGraph's router → research → orchestrator → parallel workers → reducer pipeline, with real-time research via Tavily and Markdown export.

**Stack:** LangGraph + Groq (LLaMA) · Streamlit · Tavily API · Pydantic
